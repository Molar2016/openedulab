# ADR-000 — 初始底座（待产品决策确认）

状态：**已撤回，不得据此实施**。日期：2026-10-26。用户已明确首版强制登录、所有人自行注册、不分教师学生角色，并要求先对齐需求再设计架构。本文件的免登录、静态优先及账户延期等结论均已失效；仅保留最初环境探测记录供参考。原始章程已存于 docs/CHARTER-v1.md，冲突处以用户后续澄清为准。

## 关键冲突与边界
- 用户口述：学生、教师用手机号或邮箱登录后访问资源。章程：公共核心实验免注册，登录和账户延期 P2。两者不可同时作为 M1 验收，须产品负责人选择。建议公开实验免登录；后续仅教师的个人工作区可选登录，且不采集学生手机号。
- 用户口述认为“不直接利用第三方资源盈利”即可随意引用；这不成立。即使非营利或仅收平台费，复制、改编、分发素材也需遵守许可/授权。M1 先使用原创 SVG、文字与代码；第三方依赖逐项记录许可。
- 当前只确认本机开发环境，服务器、域名、司法辖区、反代、备份、HTTPS、DNS、远端仓库均未知。不得推定可用部署 URL 或改动现有线上服务。

## 决策提案
采用 React + TypeScript + Vite 的静态优先单仓库；初期只建 apps/web 与 experiments/math-functions，不预建空 packages。纯模型函数与 UI 分离。实验元数据由源码显式导入并由脚本校验，路由根据 manifest 生成，模块动态加载；新增实验需要登记到生成清单，不修改宿主业务逻辑。SDK 在真正出现第二个异科实验前只保留最小类型契约。双语字典与实验元数据一起按需加载。分析/错误/反馈均通过可替换适配器，初期默认禁用远程发送；禁用后不妨碍实验。离线缓存、账户、收费、后台延后。

## 分层
浏览器 App Shell（目录/搜索/路由/i18n） → Experiment Host（边界/工具栏/全屏/生命周期） → Experiment Contract（manifest、组件 props、控制命令） → Experiment（纯模型 + 视图 + 测试）。横切服务：可关闭的 analytics/error/feedback adapters。静态托管为首选，生产部署另行批准。

## 风险与部署门禁
开发在独立目录及动态本机端口，不触碰已运行项目。M1 使用本机开发服务器与浏览器验收；公开测试部署先确定实际环境及隔离方式、数据流、许可与备案要求，审批后再实施。禁止自行修改 DNS、反代、防火墙或生产容器。发布采用不可变产物和回滚指针，先在测试环境验证，再考虑生产。
