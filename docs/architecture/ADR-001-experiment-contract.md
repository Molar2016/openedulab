# ADR-001 — 实验契约 v1（旧提案，须按 ADR-002 重审）

> 旧提案假设不保存参数、免登录；现首版有账号和可选显式参数快照。不得按下文直接实现，最终契约待 A 阶段确认。

状态：提案，不承诺永久稳定。React 宿主不再提供命令式 mount/unmount：模块默认导出 React 组件 `Experiment({ locale, controls, services })`，由宿主提供错误边界并随路由卸载；纯模型独立导出，便于非 DOM 测试。manifest 包含稳定 id、slug、moduleVersion、sdkVersionRange、i18n title/description、学段/主题标签、reviewedStatus；构建时验证唯一 slug、版本范围、翻译键完整性。Vite 的 import.meta.glob 显式发现实验模块，构建时生成目录，不允许模块改全局路由。

控制约定：参数保存在实验组件内；重置是宿主递增 `resetToken` 并由实验复位到公开默认参数。暂停仅对具有时间演进的实验开放；函数图像实验不伪造暂停行为。初期不持久保存状态/查询参数，以免分享隐私和迁移问题；将来需要时定义可版本化的序列化接口。全屏统一作用于宿主容器，退出由浏览器事件同步 UI。locale 由宿主传入，实验翻译键加 id 前缀。渲染错误由宿主边界展示可恢复入口并记录脱敏错误码；异步错误显式上报。卸载时 React effect 清理监听器、定时器、动画帧。实验不能直接接触分析厂商 SDK 或其它实验内部文件。

事件只允许枚举名称与白名单属性（实验 id、版本、语言、控件组、交互桶）；交互节流，禁止原始滑块轨迹和自由文本。服务缺省为 no-op。SDK 破坏性更改升级主版本并跑旧实验契约回归。第二个不同学科实验实现时复审本提案，避免为单个样例过度抽象。
