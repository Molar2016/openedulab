# 人教版初中数学旧版目录调查（仅供版别对照）

**注意：本文引用的是依据 2011 年版课标修订的旧目录，不适用于当前已下载的 2024–2026 新教材。** 本机六册 PDF 已找到且校验，新的执行基线见 `.hermes/plans/2026-10-27_141234-r9-six-volume-curriculum.md`。旧版八下 19.2／九上 22.1 不得用作新书章号；新书实际为八下 23.2／九上 26.2。本文仅保留旧版对照资料。调查日期：2026-10-27。

## 出版社资料与版别界线

- 人民教育出版社公开的八年级下册目录列第十六章二次根式、第十七章勾股定理、第十八章平行四边形、第十九章一次函数、第二十章数据的分析。第十九章下列 19.1 函数、19.2 一次函数。[1]
- 人民教育出版社公开的九年级上册目录列第二十一章一元二次方程、第二十二章二次函数、第二十三章旋转、第二十四章圆、第二十五章概率初步。第二十二章下列 22.1 二次函数的图象和性质、22.2 二次函数与一元二次方程、22.3 实际问题与二次函数。[2]
- 上面两个产品页正文明确以《义务教育数学课程标准（2011年版）》为修订依据；**不可直接当作 2022 课标新版目录**。[1][2]
- 人教社介绍按 2022 年版课标修订的新教材时，明确指出把旧教材的“一次函数”一章拆成“函数”和“一次函数”两章；第十二套新教材自 2024 年秋季起始年级投入使用。这是需要在产品中按版别分目录、分章节 ID 的实证。[3][4]
- 2011 版八年级下册产品页在第十九章里写有“14.3 课题学习 选择方案”，与该章编号不一致。资料入库先按出版社原页做校勘记录；未查到书本原版页前不把 14.3 静默改成 19.3，也不以这条作为首轮入口。[1]

## 首轮可实施映射（2011课标修订版目录）

| 册与目录条目 | 产品动作 | 判定 |
|---|---|---|
| 八年级下册：第十九章 一次函数 → 19.2 一次函数 | 复用 `math.functions` 的 `linear` 模式，预置直线参数，自制引导文字 | 适配当前工具；不把 19.1“函数”的一般定义误写成只讲直线 |
| 九年级上册：第二十二章 二次函数 → 22.1 二次函数的图象和性质 | 复用同一 `math.functions` 的 `quadratic` 模式，预置顶点/开口探究 | 适配当前工具；不宣称已覆盖 22.2 方程联系或 22.3 实际问题 |

条目名称与章序取自出版社页。[1][2] 参数、教学引导由项目自行设计，不复制教材正文、插图或第三方动画；加入来源 URL、访问日期、目录版本标识。新教材只确认了拆分事实，须另找**具体册别与完整目录**再录入，不能把上述旧版章号沿用过去。[3]

## 分段执行位置与验收

**关口 A — R8 复核与稳定提交**：单写者已改 `experiments/math-functions/curriculum.json`（两套示例）、`apps/api/src/domain/curriculum.ts`、`apps/api/src/domain/content-index.ts`、`apps/api/src/http/content-routes.ts`、`apps/web/src/app/CurriculumPage.tsx`、`apps/web/src/app/curriculum-tree.ts`，提供教材独立章序。父级先审查差异与证据，再决定提交/推送；示例 ID 不得改写成真实教材 ID。`127.0.0.1:3320` 是工作机独立测试库，本轮无需更新 VPS。

**关口 B — 真实目录首批**：新增稳定的 `catalogId/bookId/chapterId/placementId`，保留既有示例与个人快照；按八下和九上出版社目录**逐章排序**，并为 19.2/22.1 配两条 `math.functions` 入口及不同预设。没有工具的章仍要显示在目录中，而不是跳过以致顺序失真。目录内容原则上放学科级数据源，而非锁死在某工具文件；现有 R8 结构将目录嵌在工具自身的 curriculum.json 中，需要先拆出可供多个工具共用的教材树，并保持 `/api/curriculum` 旧 items 契约兼容。这是 R8 后新增的架构修正，不能以再复制一份目录到第二个工具作为长远做法。

**关口 C — 验证与交付**：对数据校验增加版别、目录唯一性、同章多工具、错误引用与顺序测试；对两册页面写导航/参数隔离/保存/重置/最近使用 E2E。跑 `npm run check`、`npm run smoke:api`、`npx playwright test`；在工作机远程桌面的浏览器打开 `http://127.0.0.1:3320/curriculum`，真实操作一次线性和一次二次入口并保存、重开回读。用户先看本机版本；VPS/公网 HTTPS 属后续独立关口。

**不把技术演示当教材完成度**：R8 两套相反顺序的“示例教材”仅用于验证排序和隔离。真实首批完成判据是出版社来源可回查、明确版别、册章完整有序、适配入口只映射确实支持的知识点，以及所有回归通过。
