# OpenEduLab 长程执行任务书（项目内生效，不需用户复制回发）

状态：执行中。日期：2026-10-26。依据：`docs/requirements-v2.1.md`、`docs/architecture/ADR-002-authenticated-platform.md`、`docs/architecture/A-stage-design.md`。冲突时以用户最新明确要求和需求基线为准；每次开工先看 `docs/PROJECT_STATE.md`。

## 最终目标与验收
完成一个可持续扩展的网页登录教学平台：任何人以手机号或邮箱加密码注册（暂不核验归属），登录后查找、打开、操作实验；收藏并查看按资源去重的最近使用；平台私有端可按账号与资源分析必要使用事件、错误和反馈。先做一款有科学依据的函数图像交互实验，手机与教室投影均可用。源码、测试、迁移、备份恢复、发布回滚与阶段证据齐全。公开上线、生产服务改动和费用另请授权。

## 组织方式：我负责调度与关门
- **产品/架构**：我维护需求基线、权限矩阵、ADR、风险与影响分析；新需求先判断影响范围，再更改任务顺序。
- **开发代理**：按隔离任务分工（API/前端/实验模型等），不得并行改同一核心文件；每项带测试与准确的实际结果。
- **独立审查代理**：只读审查结构、安全和回归；结论由我核实并安排修正，不以自报成功代替验收。
- **验收/发布**：我核验全量检查、真实页面流程、跨账号隔离、模型准确性、失败与回滚；生产动作须用户批准。
- 不要求用户把本任务书复制后再发一遍；项目状态文件负责跨会话接续。每次收尾记已完成、实际测试、失败、commit、下一条具体任务。

## 任务链与可关闭关口

| 关口 | 工序 | 退出证据 |
|---|---|---|
| R/A | 需求与架构、旧原型审计 | 需求基线、权限/事件字典、接口与风险；已落盘 |
| B0 | 修旧原型检查、建 Git 基线 | `npm run check` 和 E2E 通过、提交号；已完成 |
| B1 | 同源 API 骨架、严格配置、数据库迁移、健康检查 | 空库迁移/重启/篡改失败测试；真实本机 health 200；全检查 |
| B2 | 自注册、口令、登录/登出、会话与限速 | 成功/失败/会话过期/退出重放/未核验标识测试 |
| B3 | API 与页面资源门禁 | 未登录直达拒绝、跨账号读取拒绝；普通账号可进目录与实验 |
| B4 | **第一款真实实验闭环** + 收藏、粗粒度最近使用 | 函数模型黄金用例、投影/手机交互、跨会话收藏和去重历史；不是空框架演示 |
| B5 | 后台按账号的诊断事件、错误/反馈、受限导出 | 资源热度、交互类别、疑似问题、版本错误可由真实测试事件验证；普通账号不可见；关闭事件不影响实验 |
| B6 | 完整流程验收与可用性 | 注册→实验→收藏/历史→内部查询；三种视口、截图/短录屏、失败路径和可访问性 |
| B7 | 显式参数快照（**已完成**） | 一资源一份、版本不兼容回退；不记录逐次拖动 |
| B8 | CI、备份恢复、运维手册、状态锚收口 | 自动检查、恢复演练、回滚步骤、版本与证据 |
| D/E | 隔离测试部署→公开发布 | 先只读侦察环境并获得审批；HTTPS/数据告知/备份/回滚/上线前审查，实际 URL 回证 |

**不走“框架全部搭完才想实验”的横向路线。**已有函数实验原型只是候选素材；B2/B3 建立真实登录与门禁后，B4 就将这**一个真实实验**接入完整路径并验证公式、画面、收藏与历史。第二个异科实验在首条闭环与权限/数据链路可信后再做，用它证明扩展契约而非提前预造空包。

## 阶段规则
1. 一个工序完成 = 可运行产物 + 自动测试 + 浏览器实测/科学依据（适用时）+ 版本记录；“写了代码/建了目录”不算。
2. 上一关口失败，不把失败隐进下一关口。定位根因，增加能重现的测试，不删/放宽测试取绿。
3. 改需求/契约先更新需求追溯与 ADR，列受影响的 API、表、页面、测试和迁移，再改代码；禁止补丁式无序累积。
4. 个人收藏/历史是可靠功能；内部事件是尽力而为的诊断。二者数据和失败语义分开。
5. 公网、生产、防火墙/DNS、收费、数据采集范围扩大必须获用户明确批准。没有服务器访问与上线信息不编造网址或状态。
